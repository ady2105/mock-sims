# CAT Mock Simulator 🎯 (All-Time Toughest PYQs Edition)

A full-fledged, high-fidelity Common Admission Test (CAT) mock examination simulator built with **React**, **Vite**, **Tailwind CSS**, and styled in a **Neo-Brutalism** design aesthetic (yellow, warm orange, crisp white, bold black borders, and hard drop shadows).

Benchmarked against legendary tough CAT slots (CAT 2023 Slot 3, CAT 2020 Slot 2, CAT 2018 Slot 1) and equipped with an in-depth post-exam diagnostic evaluation engine.

---

## ⚡ Key Highlights

### 1. 62 Legendary Toughest CAT PYQs
- **VARC (20 Questions):**
  - CAT 2020 Slot 2: *Elephant Cognition & Empathy* Reading Comprehension
  - CAT 2023 Slot 3: *Romanticism, Rationalism & Instrumental Reason* Reading Comprehension
  - CAT 2021 Slot 1: *Maya & Epistemological Realism* Reading Comprehension
  - Non-MCQ / TITA Para-Jumbles (CAT 2022/2023), Para-Summaries, and Odd-Sentence-Out
- **DILR (20 Questions):**
  - CAT 2018 Slot 1: *The 100/200/500 ATM Cash Dispenser* (Classic tough optimization set)
  - CAT 2023 Slot 3: *Professor Scoring & Evaluation Matrix*
  - CAT 2017 Slot 2: *Chess Grandmasters Round-Robin Tournament*
  - CAT 2020 Slot 2: *Police Beats & Patrolling Graph Theory*
- **QA (22 Questions):**
  - CAT 2023 Slot 3: Functional equations & Cauchy-Schwarz bounds
  - Incircle-hypotenuse integer products & modular arithmetic powers
  - Circular tracks relative speed, telescoping cubic root series, and power towers

### 2. Authentic TCS iON Exam Engine
- **Sequential 40-Minute Section Locks:** Strictly adheres to official guidelines (`VARC` → `DILR` → `QA`) with auto-advance and countdown clocks.
- **Official 5-Color Question Palette:** Tactile neo-brutalist buttons tracking `Not Visited`, `Not Answered`, `Answered`, `Marked for Review`, and `Answered & Marked for Review`.
- **Split-Pane Viewer:** Horizontal and vertical split-screen for long reading passages and complex data sets.
- **Onscreen Virtual Calculator:** Retro neo-brutalist keypad supporting floating-point operations and memory registers (`MC`, `MR`, `MS`, `M+`, `M-`).
- **Official Scoring Scheme:** `+3` for correct answers, `-1` for incorrect MCQs, and `0` penalty for TITA questions.

### 3. Post-Exam Diagnostic & Assessment Report
- **Calibrated Percentile Predictor:** Calibrated against modern tough slot curves (e.g. 52 marks ~ 99%ile).
- **Top B-School Call Simulator:** Live cutoff checks across IIM Ahmedabad, IIM Bangalore, IIM Calcutta, IIM Lucknow, IIM Kozhikode, and FMS Delhi based on sectional + overall criteria.
- **4-Quadrant Time-Accuracy Matrix:**
  - *Speed Demons* (swift & accurate)
  - *Slow Grinders* (over-invested & correct)
  - *Careless Errors* (rushed & wrong)
  - *Time Sinks* (lethal score leaks)
- **Where You Are Lacking:** Behavioral anomaly audit highlighting tactical mistakes (e.g. over-investing in wrong questions, careless errors on sitters).
- **How & When to Prepare:** 3-phase strategic roadmap (Weeks 1–3 Triage, Weeks 4–7 3-Round Strategy, Weeks 8–10 Mock Marathon) with CAT D-Day execution rules.
- **Question Review & Step-by-Step Solutions:** Filterable by section and accuracy with detailed step-by-step solutions and shortcut tips.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or newer)
- npm / pnpm / yarn

### Installation
```bash
git clone https://github.com/ady2105/cat-mock-simulator.git
cd cat-mock-simulator
npm install
npm run dev
```

Visit `http://localhost:5173/` in your browser.
